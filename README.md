# 神シーンメモ

対応動画プレイヤー上に、タイムライン連動コメントを重ねて表示するChrome拡張です。  
再生画面のまま、コメントの投稿・編集・検索・前後コメントジャンプができます。

## 主な機能

- タイムライン連動コメント表示
- コメントの投稿 / 編集 / 削除
- 検索（検索開始時に動画を一時停止）
- 前後コメントへジャンプ（`Ctrl + ← / →`）
- オーバーレイの最小化 / ドラッグ移動
- コメントのローカル保存（動画ごと）
- JSONバックアップ / 復元（設定画面）
- 表示ON/OFFショートカット（初期値: `Alt + C`）

## 対応環境

- Google Chrome（Manifest V3）
- 対象ページ（URLパターン）:
  - `https://www.dmm.co.jp/digital/-/player/*`
  - `https://www.youtube.com/*`

## インストール（手動）

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. 同梱の `extension` フォルダを選択

## 使い方

1. 対応動画ページ（FANZA / YouTube）を開く
2. オーバーレイ右下の「コメント...」欄に入力して `Enter` で投稿
3. 検索欄をクリックして検索（`Esc` / `Enter` / `×` / 外側クリックで終了）
4. `Ctrl + ← / →` で前後コメントへジャンプ

## バックアップ / 復元

1. オーバーレイ右上の `⚙` を開く
2. `JSON保存` でバックアップファイル（`.json`）を保存
3. 復元時は `JSON復元` を押して保存済みファイルを選択
4. 確認ダイアログで続行すると、コメント・関連設定が復元されます

## ショートカット

- オーバーレイ表示ON/OFF: `Alt + C`（設定で変更可）
- 前コメントへジャンプ: `Ctrl + ←`
- 次コメントへジャンプ: `Ctrl + →`
- コメント入力終了: `Esc`
- 検索入力終了: `Esc` / `Enter`

## 保存仕様

- コメントはブラウザのローカルストレージ（`chrome.storage.local`）に保存されます
- 動画IDごとにデータを管理するため、作品ごとにメモを切り替えられます
- 設定画面の `JSON保存` / `JSON復元` で、コメント・UI設定の移行が可能です
- 新規ユーザーの無料枠は `50コメント` です（上限到達後は新規追加のみ不可）
- ベータ特典判定日時（JST）: `2026-05-31 23:59:59` までに初回利用したユーザーは無制限
- **注意:** 拡張機能を削除（アンインストール）すると、保存したデータも消去されます
- ブラウザ間での同期機能はありません

## トラブルシューティング

- 変更が反映されない:
  1. `chrome://extensions` で拡張を再読み込み
  2. プレイヤーページを `Ctrl + Shift + R` でハードリロード
- ショートカットが効かない:
  - 他拡張やOSショートカットとの競合を確認してください
