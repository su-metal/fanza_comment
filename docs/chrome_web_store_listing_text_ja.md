# Chrome Web Store 掲載文面（日本語）

最終更新: 2026-03-05

## アイテムの紹介

🎬 神シーンメモ は、YouTube や **DMM（デジタル動画プレイヤー）**上で「再生時間にひもづくメモ」を残せる Chrome 拡張です。

👀 視聴画面を離れずに、コメントの追加・編集・検索・ジャンプができます。

💾 メモは端末の `chrome.storage.local` に保存され、JSON でバックアップ/復元にも対応しています。
🗣️ ※ 現在のUI対応言語は日本語のみです。

✨ 視聴中に「あとで見返したい瞬間」をその場で記録でき、神シーンの取りこぼしを減らせます。

🔎 時刻付きメモを一覧・検索・前後ジャンプで素早く参照できるので、見直しやクリップ作業が効率化します。

🔒 ローカル保存が基本なので、自分のメモを自分の環境で管理しやすいのも大きなメリットです。

## 主な機能
・タイムライン連動コメント表示
・コメントの投稿 / 編集 / 削除
・コメント検索（検索開始時に動画を一時停止）
・前後コメントジャンプ（Ctrl + ← / →）
・オーバーレイの最小化 / 移動 / サイズ調整
・JSONバックアップ / 復元
・表示ON/OFFショートカット（初期値: Alt + C）

## 対応サイト
・YouTube (`youtube.com/watch*` など)
・DMM系 デジタル動画 (`dmm.co.jp/digital/-/player/*` 形式のプレイヤー)

## プラン
・無料版: 最大50コメントまで保存可能
・Pro版: 買い切りで保存数無制限
・ベータ特典: **2026-04-02 23:59:59（JST）**までに初回利用したユーザーは無制限

## データと外部通信
・コメント本文・コメント時刻・UI設定は `chrome.storage.local` に保存されます。
・コメント本文は開発者サーバーへ送信しません。
・外部通信は、動画タイトル補完（YouTube oEmbed等）とライセンス状態確認（Supabase license API）のためにのみ行います。

## 注意事項
・本拡張は非公式です。YouTube や DMM 公式プラットフォームとは関係ありません。
・スクリーンショットにはPro機能の画面を含みます。
