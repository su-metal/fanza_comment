# Chrome Web Store 掲載文面（日本語）

最終更新: 2026-03-08

## アイテムの紹介

🎬 神シーンメモ は、YouTube / DMM系デジタル動画プレイヤー上で、再生時間にひもづくメモを残せる Chrome 拡張機能です。

👀 視聴画面を離れずに、メモの追加・編集・検索・ジャンプができます。

💾 メモは端末の `chrome.storage.local` に保存され、JSON でバックアップ / 復元にも対応しています。
🗣️ 現在のUI対応言語は日本語のみです。

✨ 視聴中に「あとで見返したい瞬間」をその場で記録でき、見返したいシーンの取りこぼしを減らせます。

🔎 時刻付きメモを一覧・検索・前後ジャンプで素早く参照できるので、見直しやクリップ作業を効率化できます。

🔒 ローカル保存が基本のため、自分のメモを自分の環境で管理しやすいのも特長です。

## 主な機能
・タイムライン連動メモ表示
・メモの投稿 / 編集 / 削除
・メモ検索（検索開始時に動画を一時停止）
・前後メモジャンプ（Ctrl + ← / →）
・コメントを A/B 指定して任意区間をリピート
・オーバーレイの最小化 / 移動 / サイズ調整
・JSONバックアップ / 復元
・最新5件の自動バックアップ保持と書き出し
・表示ON / OFFショートカット（初期値: Alt + C）

## 対応サイト
・YouTube (`youtube.com/watch*` など)
・DMM系デジタル動画プレイヤー (`dmm.co.jp/digital/-/player/*` / `tv.dmm.com/vod/playback/*`)

## プラン
・無料版: 最大50コメントまで保存可能
・Pro版: 買い切りで保存数無制限
・ベータ特典: 2026-04-02 23:59:59（JST）までに初回利用したユーザーは無制限

## データと外部通信
・コメント本文、コメント時刻、UI設定は `chrome.storage.local` に保存されます。
・コメント本文は開発者サーバーへ送信しません。
・外部通信は、動画タイトル補完（YouTube oEmbed等）と Pro版のライセンス確認・再アクティベート・Stripe Checkout 開始（Supabase license API）のためにのみ行います。

## 単一用途
本拡張機能の単一用途は、YouTube および DMM系動画プレイヤーの再生中に、再生時間に紐づくメモをユーザー端末内へ記録・表示することです。
メモの投稿・編集・検索・前後ジャンプ・A/B区間リピート・JSONバックアップ/復元は、すべてこの視聴中メモ管理を実現するための補助機能です。

## 権限が必要な理由
本拡張機能は、動画再生ページ上にメモ用オーバーレイUIを表示し、再生時間に紐づくメモと設定をユーザー端末内へ保存するために権限を使用します。

- `storage`:
コメント本文、コメント時刻、表示位置、ショートカット設定、バックアップ関連データ、課金状態のローカルキャッシュを `chrome.storage.local` に保存するために使用します。

- `host_permissions`:
YouTube および DMM系動画プレイヤーの再生ページ上でメモUIを表示し、再生時間と連動させるために使用します。

- `https://wzinimxikcihdqqdvppa.supabase.co/*`:
Pro版のライセンス確認と Stripe Checkout 開始のために使用します。

コメント本文は開発者サーバーへ送信せず、ユーザー端末内に保存されます。

## 注意事項

・スクリーンショットにはPro機能の画面を含みます。
