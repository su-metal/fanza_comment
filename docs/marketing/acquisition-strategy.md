作成日: 2026-10-25（日本時間）
状態: 戦略案として記録。追加費用0円を優先し、現行のZIP配布・Xアカウント・週2件以内の原稿作成を維持する。新規の登録料・有料契約・API従量課金を使う案は採用しない。

## 位置付けと現行運用との境界

この文書は、認知からインストール・継続利用までの目標と施策案を記録する。ここに記載した案だけでは、公開先、アカウント、投稿頻度、計測実装を変更したことにはならない。

- 現行LPはCloudflare Pagesで公開し、Chrome Web Storeを経由しないZIPを配布している。Chrome Web Storeの開発者登録には一回限りの登録料が必要なため、0円を守る間は現行のZIP配布を維持する。既に登録済みで追加費用がないかは未確認。
- 現行のX投稿先はユーザー指定の `@awawawawawadama`。専用アカウントへの分離は本戦略の提案であり、アカウント変更は未決定。
- 既存の定期運用は月曜・木曜9時（日本時間）の原稿作成・状況確認で、X原稿は週2件を上限としている。本戦略の初期目安「週3回程度」とは頻度が異なるため、運用上限は別途決定するまで既存の運用手順に従う。
- 無料上限、価格、機能、対応環境、保存・通信の説明は、公開時点の実装と要件定義を確認してから使用する。
- GA4専用プロパティは作成済みで、LP・ガイドのタグと公開説明をローカル実装したが本番未反映。導入完了や継続利用の取得方法は未設定。拡張内のコメント本文や視聴情報は集客計測に使わない。
- 追加費用0円を守る。新規の有料契約・登録料・API従量課金を使わず、Xは投稿APIを呼ばない手動投稿とする。計測はSearch ConsoleとGoogle Analytics 4（GA4）を使う。GA4の標準自動収集範囲を公開説明し、カスタムイベントやZIPクリックは初期対象外とする。

## 目標

FANZAのブラウザー視聴中に「見返したい場面」を保存したい人に神シーンメモを知ってもらい、LPで使い方と安心材料を伝え、インストールにつなげる。

認知から利用までを次の流れで設計する。

- X・検索・記事・コミュニティ
- FANZA向けだとすぐ分かるLP
- 配布ページと導入手順
- インストール
- 最初の場面を保存
- 継続利用・Pro購入

## 商品の中心メッセージ

神シーンメモは、ChromeでFANZAを視聴しながら、好きな再生位置を複数保存し、あとからその場面にすぐ戻れる拡張機能。

動画ファイルをダウンロードするツールではない。ブラウザーで視聴中に、自分の見返したい位置を記録するツールとして説明する。

### 代替機能との境界

FANZA公式のDMM Player v2にも、お気に入り場面へのチャプター追加とチャプター間のABリピートがある。公式ヘルプが説明するのは動画ファイルを開くデスクトッププレーヤーなので、神シーンメモは「唯一のシーン保存手段」とは訴求しない。Chromeのブラウザー視聴中に時刻と文章メモを端末内へ残せる点を、対象環境の違いとして具体的に伝える。[FANZA公式ヘルプ](https://support.fanza.jp/digital/article/46515)

### LPで維持する表現方針

- メインコピー: 「FANZAの、あそこ。また観たい。でしょ？」
- ファーストビューに「FANZA ブラウザ視聴向け」と明記する。
- 困りごとは「毎回同じシーン探してない？」のように、実感に近い会話調で伝える。
- 男性の「もう一度見たい」気持ちに寄せる。下世話さを適度に入れ、変にポエミーにしない。
- 「抜きどころ」「オカズ」などは合う場所で使う。「執着」「しつこい」は使わない。「何度でも」は使用可。
- すべての見出しを扇情的にせず、機能説明と欲望を煽る表現を配置ごとに使い分ける。
- 無料上限50件、Pro買い切り500円は、現行仕様と一致することを確認してから掲載する。
- 黒・ピンク版と白版の切り替え、読みやすい文字、操作が分かるデモを用意する。

## 配布方式

「野良配布」は、Chromeウェブストアの検索結果に頼らず、XやLPから利用者を案内する形で実現する。

0円を優先する間は、LPから現在のZIPを配布し、手動インストール・更新の手順を明確にする。Chrome Web Storeの限定公開（Unlisted）は導入負荷を下げる候補だが、開発者登録に一回限りの登録料が必要なため、既存登録で追加費用がないと確認できるまで採用しない。

現在のストア掲載がYouTube向けに見える場合は、機能・対象サイト・説明・画像の不一致を確認し、FANZAのブラウザー視聴で使う機能が正確に伝わる掲載内容に直す。ストア掲載内容は実装済み機能とポリシーに合わせる。

## 集客チャネル

### 1. X: 主な認知獲得チャネル

既存の個人開発アカウントに成人向けの話題が混ざる懸念があるため、神シーンメモ用アカウントを分ける案を基本にする。

プロフィールには、FANZA視聴中に場面を保存・再生できるChrome拡張だと短く書く。プロフィールと固定ポストからLPへ誘導する。

投稿の柱:

1. 悩みの提示
   - 例: 「FANZAで毎回同じシーン探してない？」
2. 操作デモ
   - 作品内の複数ポイントを保存し、一覧から戻る画面を短いGIFや動画で見せる。
3. 使い方
   - インストール、保存、再生位置への戻り方を画面付きで説明する。
4. 不安の解消
   - 何を保存するか、動画をダウンロードするのか、無料範囲、対応環境などをFAQ形式で答える。仕様を確認してから掲載する。
5. 開発・更新情報
   - 追加した機能、改善点、利用者の声を事実に基づいて投稿する。

初期は週3回程度を目安に、悩み・操作デモ・使い方を組み合わせて反応を確かめる。投稿文をそのまま大量に繰り返したり、無関係な投稿への宣伝返信を繰り返したりしない。

投稿素材は拡張機能の画面を中心にする。成人向け映像や作品画像を宣伝素材に使わず、プロフィール画像とヘッダーも一般向けのデザインにする。投稿内容がセンシティブなメディアに該当する場合は、Xのラベル設定を確認する。

### 2. SEO: 困りごとを検索する人の受け皿

まずLPのタイトル、説明文、H1、本文、FAQで、対象と機能を明確にする。メインコピーの印象を残しながら、検索エンジンにも「FANZA向けのシーン保存拡張」だと分かる構成にする。

キーワード候補:

- FANZA シーン 保存
- FANZA 動画 ブックマーク
- FANZA 動画 再生位置 保存
- FANZA タイムスタンプ メモ
- FANZA 同じシーン 何度も見る
- FANZA 好きな場面 しおり
- FANZA ABリピート ブラウザ（ABリピートが現行機能であることを確認してから使う）

検索数や競合状況は未確認のため、これらは仮説キーワードとして扱う。実際の検索パフォーマンスと利用者の言葉に合わせて見直す。

LPに加えて、実際の画面や使用経験を使った解説を作る。

- FANZA視聴中に見返したい場面を保存する方法
- ひとつの作品に複数の再生位置を記録する使い方
- 神シーンメモの導入方法、料金、対応環境、保存・削除の説明

同じ内容をキーワードだけ差し替えて大量のページにしない。製品を作った本人だから説明できる、具体的な操作と制限を載せる。

### 3. AIO: AI検索で正確に説明・引用される状態を整える

Google AI Overviews／AI Mode、Microsoft Copilot、ChatGPT Search、Perplexityから、製品情報を正確に取得できるようにする。

LPやFAQに、次の情報を明記する。

- 神シーンメモとは何か
- どの環境・サイトで使えるか
- 再生位置をどのように保存して戻るか
- 動画自体をダウンロードするのか
- 無料範囲とProの価格
- 導入、更新、削除方法
- データの保存先や外部送信の有無（実装を確認した事実だけを書く）
- 開発者、問い合わせ先、最終更新日

見出しを質問文にし、その直後に簡潔で具体的な回答を書く。機能、価格、対応環境、データの扱いはLP、ストア掲載、Xプロフィールで一貫させる。

検索エンジンやAI検索からLPを取得できるようにする。

- 公開ページがログインなしで読め、HTML本文として製品情報を含むことを確認する。
- robots.txt、CDN、WAF、CAPTCHAでGooglebot、Bingbot、OAI-SearchBot、PerplexityBotを誤って遮断しない。
- Google Search ConsoleとBing Webmaster Toolsにサイトを登録し、サイトマップとインデックス状態を確認する。
- Bing Webmaster ToolsのAI Performanceで、AI回答に引用されたページや検索語を確認する。
- ChatGPT SearchやPerplexityからの流入をアクセス解析で区別できるようにする。

AI検索向けの特別な裏技を前提にしない。Googleは通常のSEO、クロール可能性、独自性のある有用な情報を重視し、Google検索での表示にllms.txtや専用のAIマークアップは不要としている。

### 4. note・解説記事

noteでは、機能紹介だけでなく「どんな場面で便利か」「保存から再生までの流れ」を画面付きで説明する。FANZA作品への直リンクを前提にせず、LPと配布ページへ案内する。

LP本文の丸写しではなく、記事独自の使い方や開発背景を加える。記事からLPへのリンクは現在のcanonical URLを使う。UTMを集計できる無料手段が確認できた場合のみパラメータを付け、未接続の計測を実施済みとして扱わない。

### 5. コミュニティ・外部紹介

FANZA利用者やブラウザー拡張に関する質問・会話を探し、宣伝だけの投稿ではなく、質問への回答として必要なときに紹介する。各コミュニティの宣伝ルールに従い、開発者本人であることを隠さない。

実際に使った人のレビュー、個人開発紹介、拡張機能紹介ページへの掲載を目指す。虚偽レビュー、購入・交換による評価操作、依頼元を隠した紹介、無関係な場への一斉投稿は行わない。

### 6. 有料広告

初期の主軸にはしない。Google広告やX広告では成人向け・性的なカテゴリーに制限があり、広告文、画像、遷移先、対象地域・年齢によって審査や配信制限を受ける可能性がある。出稿を試す場合は、事前に各広告ポリシーと実際の審査可否を確認する。

## 計測

無料で取得できる範囲で次を記録し、取得できない指標は未取得と明記する。

- Xの投稿表示、プロフィール訪問、リンククリック
- LPの訪問数と流入元
- 配布ZIPのクリック数（無料計測手段は未確認）
- インストール数（ZIPクリックとは区別し、直接確認できる場合のみ記録）
- 初回の場面保存、継続利用、Pro購入（計測する場合はプライバシー説明と実装を確認する）

Search Consoleでは検索語、表示回数、クリック数、掲載順位を確認する。Bing Webmaster Toolsでは検索語とAI回答での引用状況を確認する。ChatGPT SearchやPerplexityからの流入も、取得できる範囲で分析する。

最初に現状値を記録し、4週間ごとに「認知」「LP訪問」「インストール」のどこで離脱しているかを見て、投稿内容とページを改善する。

2026-10-25の公開後確認では、Actions run `40189387684` が成功し、v1.0.3のLPと配布ZIPが本番へ反映された。Search Consoleの所有権確認とサイトマップ再送信成功は記録済みだが、最新レポートは未確認。2026-10-30にGA4専用プロパティを作成し、トップと2つのガイドにタグと計測説明を追加する変更を準備したが、本番未反映で実測値は未取得。Cloudflare Pages MetricsではWeb Analyticsが有効と表示されるため、GA4公開後に無効化して二重計測を避ける。GA4は標準ページビューと参照元の確認に使い、カスタムイベント・ZIPクリックは初期対象外とする。詳しい事実と制約は[製品事実・計測確認表](product-facts.md)を参照する。
