# 実際の悩みから選ぶSEOキーワード調査

調査日: 2026-10-24（日本時間）  
対象: 神シーンメモ / Scene Memo。日本語SEOを中心に、FANZA・DMMの利用者の声と、対応サイトであるYouTubeの利用者の声を調べた。

## 結論

- 悩みとして確認できたのは、動画内の位置を覚えておきたい、同じ場面を見返したい、見どころの時間をメモしたい、自分用の目印を公開コメント欄に置いている、という行動・要望。
- FANZAの利用者が同じ場面を繰り返し見る行動は一次投稿で確認した。一方、PCブラウザでの場面保存機能を求める直近の独立した相談は今回十分に確認できなかった。FANZA向けキーワードの検索需要が立証されたとは扱わない。
- DMMの位置記録・しおりの要望にはレビュー転載の根拠があるが、古いAndroidアプリやVRアプリの話であり、PC版Chrome向けの需要へそのまま換算できない。
- YouTubeでは、日本語の利用者記事に見どころの時刻を記録する実務と手間が記されている。自分用タイムスタンプの保存は、現行機能との接点が比較的明確。
- 最初の検証記事は、事業上の本命であるFANZAの「動画内の場面・再生位置を保存」と、悩みの根拠が比較的厚いYouTubeの「タイムスタンプを自分用に保存」を各1本とする案を推奨する。記事の採用・公開は未決定。
- 以前の計画に挙げた「FANZA ABリピート」は機能との適合性は高いが、独立したPCブラウザ利用者の相談という根拠は今回確認できなかった。単独記事の最優先候補から検証枠へ下げる。

## 調査方法と限界

公開Web検索で、FANZA・DMMの場面保存、再生位置、しおり、チャプター、リピート、YouTubeの自分用タイムスタンプに関する検索式を36通り使用した。一般検索、質問サイト、掲示板、レビュー、利用者の個人記事を探索し、候補ページを開いて本文を確認した。本文が取得できなかったページは検索取得抜粋であることを明示した。

本調査は定性的な困りごとの探索であり、投稿者が実際に入力した検索クエリのログ、Googleサジェスト、月間検索数、検索順位、SEO難易度の測定ではない。以下のキーワードは投稿から導いた候補で、利用者がそのまま検索したと確認できた語句ではない。投稿やレビューの件数から市場規模を推定していない。英語の投稿は補助資料であり、日本語の検索需要や中国語・韓国語の需要の証拠にはしていない。

証拠の種類を分ける。

- 一次資料: 投稿者自身の体験・相談が、投稿先の本文で確認できたもの。
- 転載: レビュー転載サイトで本文・掲載日を確認したもの。元ストアでの照合はできていない。
- 検索取得抜粋: 検索で投稿内容を取得できたが、直接のページ本文を再取得できなかったもの。
- 開発者発信: 自分のツールを紹介する投稿。独立した顧客の需要とは数えない。
- 公式説明: 機能の有無や検索意図の確認に使い、悩みの件数には数えない。

## 利用者の声と適合性

### S1: FANZAで同じ場面を繰り返し見る

- 出典: [FANZAアカウントの削除を決めました](https://anond.hatelabo.jp/20231031101457)
- 投稿日: 2023-10-31。一次資料・本文確認済み。匿名投稿であるため、実体験の独立した検証までは行っていない。
- 観察: 購入した動画の同じ場面を繰り返し視聴する行動が書かれている。
- 推論: 場面単位の目印と再訪に接点はある。ただし、位置を探す作業に困っている、しおり機能を求めている、とまでは書かれていない。
- 導く候補: `FANZA 好きなシーン 再生位置`、`FANZA 動画内 ブックマーク`。
- 制限: 記事の主題には家族への履歴露出の懸念もあるが、本拡張はブラウザの履歴削除・家族からの秘匿を提供しない。その悩みを解決すると宣伝しない。

### S2: 特定の位置を覚える、しおりが欲しい

- 出典: [DMM動画プレイヤーのレビュー一覧（Chrome-Stats）](https://chrome-stats.com/d/com.dmm.app.movieplayer/reviews)
- 対象レビュー日: 2019-12-06。転載・本文確認済み。対象はAndroidアプリ。
- 短い原文: 「しおり機能的なものがあると嬉しい」
- 観察: チャプターのスキップと、動画内の特定位置を記憶する機能が求められている。
- 推論: 「しおり」「位置を覚える」は利用者側の表現として採用候補。FANZAのPCブラウザ検索需要が現在もあるという証拠にはしない。
- 導く候補: `FANZA 動画 しおり`、`FANZA 動画 再生位置 保存`。
- 元ストア本文は取得できず、Google Playでの原文の再照合は未実施。転載サイトの自動生成されたレビュー要約は証拠に用いず、該当レビュー本文だけを使用した。

### S3: 多数のチャプターの中から、お気に入りを選んで戻りたい

- 出典: [DMM VR動画プレイヤーのカスタマーレビュー転載](https://www.app-ranking.net/id/1134925341)
- 対象レビュー日: 2026-02-25。転載・本文確認済み。
- 観察: チャプターが多数ある作品について、チャプターごとのお気に入りを求める要望がある。
- 推論: 作品全体の「お気に入り」と、動画内の場面を残す機能は別の要望。
- 制限: 対象はiPhone系VRアプリ。神シーンメモはこの環境に対応しない。VR、iPhone、スマホを主語にした集客記事には使わない。

### S4: 見どころの時間を手で記録し、あとから確認し直すのが手間

- 出典: [作ってみよう！タイムスタンプ](https://note.com/inruioroka/n/n6fbb735ddea3)
- 投稿日: 2025-07-26。一次資料・本文確認済み。
- 観察: 配信のファンがタイムスタンプを作成してきた経験を説明している。手書きの記録や、アーカイブを後で見返して時刻を拾う手順には追加の手間があり、PCの拡張機能を実際に使っている。
- 推論: 機能名より「見どころ」「時間をメモ」「見ながら記録」に具体的な課題との接点がある。
- 導く候補: `YouTube 見ながら メモ タイムスタンプ`、`配信 アーカイブ 見どころ メモ`。
- 制限: 記事には公開コメント用のタイムスタンプ作成も含まれる。神シーンメモには、公開コメントの自動投稿やタイムスタンプ一覧のテキスト書き出し機能があるとは説明しない。時短の数値は筆者自身の体験であり、本拡張の効果に転用しない。

### S5: 「ここ好き」を時間と説明で残すが、公開コメントには配慮が必要

- 出典: [YouTube配信における時間指定（タイムスタンプ）について](https://note.com/mtg_pact/n/n431b00fd85f4)
- 投稿日: 2024-01-06。一次資料・本文確認済み。
- 観察: Chromeの既存拡張機能を使って、動画内の時刻と内容を記録する実際の手順が示されている。公開する際の重複や文言への配慮も述べられている。
- 推論: 同じ視聴中の記録でも、他人に向けて公開する用途と、個人用に残す用途を分けると、記事の目的が明確になる。
- 導く候補: `YouTube タイムスタンプ 自分用`、`YouTube ここ好き メモ`。
- 制限: 公開すること自体を望む人もいる。全利用者が非公開を求めているとは推定しない。

### S6: 好きな場面に戻るため、公開コメント欄を使っている

- 出典: [YouTubeの動画にコメント書き込む？](https://girlschannel.net/topics/5935107/)
- 対象投稿日時: 2025-11-23 19:03:05（トピック先頭投稿）。検索取得抜粋のみ。ページの直接取得と公開HTTP取得は完了できなかった。
- 観察: 好きな動画の好きな場面をすぐ見られるよう、コメント欄に時刻を付けているという行動が記されている。
- 推論: 自分用の目印を動画内に残す需要の補助根拠となる。ただし、この投稿だけでは非公開にしたいという希望まで確認できない。
- 導く候補: `YouTube タイムスタンプ 自分用 保存`、`YouTube 好きな場面 ブックマーク`。

### S7: 長い動画の途中に戻りたい。既存の時刻付きURLで解決する場合もある

- 出典: [Way to create timestamped bookmarks within videos?](https://www.reddit.com/r/youtube/comments/nb2g7n/)
- 投稿日: 検索取得情報で2021-05-12。一次資料・本文確認済み。英語の相談。
- 観察: 長い講義動画や再生リストの中で、視聴を中断した位置を記録したいという質問。返信では時刻付き共有リンクをブラウザに保存する方法が示され、質問者は解決したと応答している。
- 推論: 一つの位置に戻るだけなら、標準機能で足りることもある。拡張の紹介記事は、複数の位置・文章メモ・検索をまとめる用途まで説明する必要がある。
- 制限: 自動レジュームと端末間同期も相談内容に含まれる。本拡張は自動記録・自動同期の解決策とはしない。

### S8: PCプレイヤーを閉じたあとに続きから見たい

- 出典: [DMMの動画プレイヤー「DMM Player v2」の解説](https://analog-to-digital.seesaa.net/article/474202770.html)
- ページ表示日: 2020-05-23。更新欄には2024-01-26等の履歴あり。一次資料・本文確認済み。
- 観察: 筆者の利用環境で、プレイヤーを閉じた際の再開に不便を感じたとの記述がある。
- 制限: 古いアプリの利用感であり、現在のPCブラウザの不具合の証拠にはしない。神シーンメモは最後に視聴した位置を自動保存する製品ではないため、`FANZA 続きから 再生できない` を主な集客語に選ばない。

## 公式機能・検索意図の確認

### O1: 「ブックマーク」は作品のお気に入りにも使われる

[FANZA公式・お気に入り商品リストの説明](https://support.fanza.jp/digital/article/48457)は、商品をブックマークする機能として説明している。今回の検索取得結果でもこのページや作品のお気に入り解説が現れた。`FANZA ブックマーク` だけでは、動画内の再生位置を探す意図と区別しにくい。

`FANZA しおり` の探索では、FANZAブックスのしおり説明や人名も混ざった。主なタイトルには「動画」「動画内」「再生位置」「PCブラウザ」を追加して意味を限定する。

### O2: チャプター・ABリピートは公式PCアプリにも存在する

[FANZA公式・DMM Player v2の機能説明](https://support.fanza.jp/digital/article/46515)で、チャプター追加とチャプター間のリピートを確認した。したがって「FANZAにはチャプターやABリピートがない」という主張はしない。記事では、公式アプリの機能説明と、対応するPCブラウザ上でメモする本拡張の利用範囲を説明する。

### O3: YouTube向けには既存の拡張も検索に現れる

候補語の探索では[YouTube Timestamp](https://chromewebstore.google.com/detail/youtube-timestamp/ohgopfafehbphdlmdiamepjbmeliipfm?hl=ja)など、時刻とメモを保存する既存のツールも取得された。競合の存在は確認したが、検索順位の順位表、利用実績、競合の機能検証は行っていない。「競合が少ない」「簡単に上位を取れる」とは評価しない。

## 主な集客語にしないもの

| 語句・意図 | 選ばない理由 |
|---|---|
| FANZA ブックマーク / お気に入り | 作品全体のお気に入りを探す意図と混ざる。動画内の位置と限定して使う |
| FANZA 保存 / ダウンロード / MP4 / 録画 / 切り抜き保存 | 本拡張は動画ファイルを保存しない |
| FANZA 再生できない / 遅い / エラー | 本拡張は配信サービスやDRM、通信の不具合を修復しない |
| FANZA 続きから / 自動レジューム | 最後に再生した位置を自動保存・再開する機能とは異なる |
| FANZA VR お気に入り / iPhone しおり | 相談は見つかったが現行の対応環境外 |
| YouTube タイムスタンプ 作り方 / チャプター 設定 | 投稿者による動画の目次作成や、公開コメントの作成という意図と混ざる。「視聴者」「自分用」「保存」を明記する |
| YouTube コメント 消えた | 公開コメントの復旧はできない。自分用メモを残す別の方法として紹介する場合のみ扱う |
| 動画メモ 自動同期 / 自動要約 / 文字起こし | 本拡張が提供していない機能 |

## 最初の2記事の提案

1. **FANZAの好きな場面を保存する方法｜PCブラウザで再生位置にメモを残す**
   - 検証する主語: `FANZA 動画 再生位置 保存`。
   - 冒頭で、保存対象は時刻とメモであると明記する。対応するPC版Chromeの利用範囲、複数メモ、頭出し、メモ検索を実際の手順で説明する。
   - 作品全体のお気に入りや、公式DMM Player v2で使えるチャプターも説明し、既存機能の欠如を誤って主張しない。ABリピートはこの記事の機能紹介・FAQで扱う。
   - FANZAのPCブラウザ需要は仮説段階のため、この記事の表示クエリを見て主語を調整する。
2. **YouTubeのタイムスタンプを自分用に保存する方法｜コメント欄に投稿せず残す**
   - 検証する主語: `YouTube タイムスタンプ 自分用 保存`。
   - 一つの再生位置だけを残す場合には、標準の時刻付きURLも選択肢として説明する。複数の場面に文章を付け、あとで検索したい場合に本拡張の手順を示す。
   - 非公開のローカルメモ、端末間同期なし、JSONバックアップ、ZIPによる手動導入を説明する。公開コメント自動投稿やタイムスタンプ一覧のテキスト書き出しは約束しない。
   - YouTubeの利用方法を読みに来た人が、その説明と導入手順へ直接進めるページにする。

## 公開後に確認すること

- Search Consoleで、ページが取得・インデックスされているかを先に確認する。
- 公開から約4週間の表示クエリ、表示回数、クリック、ページ別LP流入とZIPクリックを確認する。4週間は初回観察の目安であり、成果が出る期限やSEOの成否を断定する基準ではない。
- 作品お気に入り、ダウンロード、スマホ、VRの検索が混ざる場合は、タイトルと冒頭の対象環境・保存対象の説明を具体化する。
- 表示がない場合は、需要ゼロとは断定せず、インデックス・クロール・計測期間・ページの内容を確認する。
- サイト別に仮説を評価し、YouTubeで観測した需要をそのままFANZAの需要として記録しない。独立したFANZA PC利用者の相談や、該当する検索クエリが得られたときに優先度を再評価する。
