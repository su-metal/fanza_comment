神シーンメモ - 導入方法（PC版 Chrome）
========================================

この拡張機能は Chrome Web Store を経由しない ZIP 配布版です。
ZIPを解凍し、Chromeの「デベロッパーモード」から読み込んでください。

初回インストール
----------------
1. ZIPを解凍し、展開したフォルダをPC上の保存場所に置きます。
   このフォルダは、拡張機能を使う間は移動・削除しないでください。
2. Chromeのアドレスバーに chrome://extensions と入力して開きます。
3. ページ右上の「デベロッパーモード」をONにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
5. 手順1で解凍したフォルダのうち、manifest.json が入っているフォルダを選びます。
   ZIPファイル自体や、そのフォルダのひとつ上のフォルダは選ばないでください。
6. 対応サイト（FANZA / DMM TV / YouTube）の対象動画ページを開くか、再読み込みします。

ツールバーに表示する
--------------------
Chrome右上の拡張機能アイコン（パズル形）をクリックし、
「神シーンメモ」の横にあるピンを選ぶと、ツールバーに固定できます。

更新
----
Chrome Web Store経由の自動更新はありません。
新しいZIPで更新するときは、現在読み込んでいるフォルダへ新しいファイルを上書きし、
chrome://extensions に戻って「神シーンメモ」の再読み込みアイコンをクリックしてください。

アンインストール前の注意
------------------------
コメントと設定はブラウザ内に保存されます。拡張機能を削除すると保存データも
削除されるため、必要なメモは設定画面からJSONバックアップを保存してください。

困ったとき
----------
・読み込みに失敗する場合は、manifest.json が入ったフォルダを選んだか確認してください。
・変更が反映されない場合は、chrome://extensions で拡張機能を再読み込みし、
  動画ページも再読み込みしてください。
