Scene Memo - Installation Guide (Desktop Chrome)
================================================

This extension is distributed as a ZIP file outside the Chrome Web Store.
Extract the ZIP and load the folder in Chrome with Developer mode enabled.

Install
-------
1. Extract the ZIP to a folder on your computer. Keep this folder in place
   while you use the extension; do not move or delete it.
2. In Chrome, enter chrome://extensions in the address bar.
3. Turn on Developer mode at the top-right of the page.
4. Click Load unpacked.
5. Select the extracted folder that contains manifest.json. Do not select
   the ZIP file or the parent folder.
6. Open or reload a supported video page on FANZA, DMM TV, or YouTube.

Pin the extension
-----------------
Open Chrome's Extensions menu (the puzzle-piece icon) and click the pin next
to Scene Memo to show it on the toolbar.

Update
------
This version does not update automatically through the Chrome Web Store.
To update, extract the new ZIP over the currently loaded folder, then return
to chrome://extensions and click the reload icon on Scene Memo.

Before uninstalling
-------------------
Comments and settings are stored in your browser. Removing the extension
also deletes this data. Export a JSON backup in the extension settings first
if you need to keep your notes.

Troubleshooting
---------------
- If loading fails, make sure you selected the folder containing manifest.json.
- If a change does not appear, reload Scene Memo at chrome://extensions and
  then reload the video page.
