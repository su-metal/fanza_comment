명장면 메모 - 설치 안내 (데스크톱 Chrome)
=========================================

이 확장 프로그램은 Chrome 웹 스토어가 아닌 ZIP 파일로 배포됩니다.
ZIP을 압축 해제한 뒤 Chrome에서 개발자 모드를 켜고 폴더를 불러오세요.

처음 설치하기
-------------
1. ZIP을 컴퓨터의 폴더에 압축 해제합니다. 사용하는 동안 이 폴더를 이동하거나
   삭제하지 마세요.
2. Chrome 주소창에 chrome://extensions 를 입력해 엽니다.
3. 페이지 오른쪽 위에서 개발자 모드를 켭니다.
4. 압축해제된 확장 프로그램을 로드 버튼을 클릭합니다.
5. manifest.json 파일이 들어 있는 압축 해제 폴더를 선택합니다. ZIP 파일이나
   상위 폴더를 선택하지 마세요.
6. FANZA, DMM TV 또는 YouTube의 지원 동영상 페이지를 열거나 새로고침합니다.

툴바에 고정하기
---------------
Chrome 오른쪽 위의 퍼즐 모양 확장 프로그램 메뉴를 열고,
명장면 메모 옆의 핀 아이콘을 클릭하면 툴바에 표시됩니다.

업데이트
--------
Chrome 웹 스토어를 통한 자동 업데이트는 제공되지 않습니다.
새 ZIP을 현재 불러온 폴더에 덮어쓴 뒤 chrome://extensions 에서
명장면 메모의 새로고침 아이콘을 클릭하세요.

삭제하기 전에
-------------
메모와 설정은 브라우저에 저장됩니다. 확장 프로그램을 삭제하면 이 데이터도
삭제되므로, 메모를 보관하려면 설정에서 먼저 JSON 백업을 내보내세요.

문제 해결
---------
- 불러오기에 실패하면 manifest.json이 들어 있는 폴더를 선택했는지 확인하세요.
- 변경 사항이 보이지 않으면 chrome://extensions 에서 확장 프로그램을 새로고침한
  다음 동영상 페이지도 새로고침하세요.
