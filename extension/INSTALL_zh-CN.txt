神场景笔记 - 安装指南（桌面版 Chrome）
========================================

本扩展通过 ZIP 文件分发，不经过 Chrome 网上应用店。
请先解压 ZIP，再在 Chrome 中开启“开发者模式”加载文件夹。

首次安装
--------
1. 将 ZIP 解压到电脑上的文件夹。使用扩展期间请勿移动或删除此文件夹。
2. 在 Chrome 地址栏输入 chrome://extensions 并打开。
3. 打开页面右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后包含 manifest.json 的文件夹。不要选择 ZIP 文件或它的上级文件夹。
6. 打开或刷新 FANZA、DMM TV 或 YouTube 的受支持视频页面。

固定到工具栏
------------
点击 Chrome 右上角的扩展程序拼图图标，然后点击“神场景笔记”旁边的图钉，
即可将扩展固定到工具栏。

更新
----
此版本不会通过 Chrome 网上应用店自动更新。
更新时，将新 ZIP 解压并覆盖当前加载的文件夹，然后打开 chrome://extensions，
点击“神场景笔记”卡片上的重新加载图标。

卸载前请注意
------------
评论和设置保存在浏览器中。卸载扩展也会删除这些数据；如需保留备忘，
请先在扩展设置中导出 JSON 备份。

故障排除
--------
- 如果加载失败，请确认选择的是包含 manifest.json 的文件夹。
- 如果更改没有生效，请在 chrome://extensions 中重新加载扩展，然后刷新视频页面。
