06 / INSTALL WITHOUT A STOREZIPを使った手動インストール

3ステップで、
Chromeに追加。

神シーンメモはChrome Web Storeを経由せず、配布ZIPを使って手動でインストールします。日本語・英語・簡体字中国語・韓国語の導入手順書もZIP内に同梱しています。

01

ZIPをダウンロードして解凍

ZIPを保存して解凍します。解凍後、manifest.json が入っているフォルダを確認してください。

拡張機能ZIPをダウンロード ↓
02

Chromeの拡張機能ページを開く

アドレスバーに chrome://extensions と入力し、ページ右上の「デベロッパーモード」をONにします。

03

解凍したフォルダを読み込む

「パッケージ化されていない拡張機能を読み込む」を押し、manifest.json があるフォルダを選びます。これで準備完了です。

Chrome Web Store版ではないため自動更新はありません。更新時は新しいZIPを同じフォルダへ上書き解凍し、chrome://extensions で拡張機能を再読み込みしてください。

07 / BEFORE YOU DIVE IN大事な話は、まじめに。

よくある質問

動画のダウンロードは必要ですか？＋

動画ファイルをダウンロードする必要はありません。神シーンメモをPC版Chromeに追加し、対応するFANZAのブラウザ再生ページを開いて使います。保存するのは再生時刻とメモで、動画そのものを保存・ダウンロードする機能ではありません。

DMM Player v2のチャプター機能とは何が違いますか？＋

DMM Player v2は、ダウンロードした動画を再生する公式のPC用プレーヤーで、チャプター追加やチャプター間リピートに対応しています。神シーンメモは、対応するFANZA動画をChromeでブラウザ視聴しながら、場面に文章メモを付けて保存・検索・頭出しできる非公式の拡張機能です。DMM Player v2内で動作するものではありません。公式プレーヤーの機能を確認する ↗

FANZAの動画内の再生位置をブックマークできますか？＋

対応するFANZAプレーヤーで、好きなシーンの再生時刻とメモを保存できます。1本の動画に複数の場面を登録し、メモをクリックしてその時刻へ移動できます。作品そのものを登録するお気に入り機能とは異なります。

FANZAのブラウザ再生でABリピートできますか？＋

対応するFANZAプレーヤー上で、保存した2つのメモをA（開始）とB（終了）に指定すると、その区間を繰り返し再生できます。PC版Chrome向けの機能です。

FANZA以外でも使えますか？＋

YouTubeとDMM TVにも対応しています。FANZAは dmm.co.jp/digital/-/player/、DMM TVは tv.dmm.com/vod/playback/ 配下の対象ページ向けです。サービス内のすべてのプレーヤーへの対応を保証するものではありません。

スマートフォンでも使えますか？＋

本ページではPC版Google Chrome向けの拡張機能をご案内しています。スマートフォン向けアプリではありません。

メモは誰かに見られますか？＋

メモは利用中のブラウザ内に保存され、他の利用者に公開されません。コメント本文は開発者サーバーへ送信しません。動画タイトルの取得、Proのライセンス確認・購入処理などでは外部通信が発生します。

LPの利用状況は計測されますか？＋

Cloudflare Web Analyticsが有効な場合、このLPとFANZAガイドのページ閲覧数・読み込み性能をCloudflareへ送って集計します。CloudflareはCookieを使わず、訪問者の個人データを収集・使用せず、同社の顧客サイト間で利用者を追跡しないと説明しています。拡張機能内のメモ本文、動画ID、動画タイトル、再生位置、利用状況はこのサイト計測の対象外です。

PCの変更やアンインストール時はどうなりますか？＋

端末間の自動同期はありません。設定からJSONバックアップを書き出し、移行先で復元できます。拡張機能をアンインストールすると保存データも削除されるため、先にバックアップしてください。

公式サービスですか？＋

個人開発の非公式ツールです。FANZA・DMM・YouTubeの公式サービスとは関係ありません。プレーヤーの仕様変更により動作しなくなる場合があります。
